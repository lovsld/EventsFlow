## 2. F 预算执行验收细节（任务书 §2.2）

- 定义与配置：narrative/f_budgets.json（F1 ≥ 0.30、F2 0.40–0.55、
  F3 ≤ 0.20，实验值、可配置）。Phase 1 时期预算只在生成后统计，
  生成期仅有提示词软约束——本次验收确认该状态并补齐闭环。
- 闭环实现（writer2._enforce_budget）：生成后测量 → 按书级缺口
  计算需转化的 F3 段数（同时满足 F3 上限与 F2 下限、不越 F2 上限）
  → 定向改写（转动作/对话/场景呈现；禁新增事实与引语；段数、
  顺序、event_ids 不变；改写不合格整章拒绝）→ 复测 → 仍超标则
  状态与问题清单写入 trace（over_budget_after_rewrite），绝不静默。
- 对照（酒馆同一事件流，Gemini）：OFF（软提示）F3 0.179 合格但
  F2 0.304 低于下限；ON v1 F3 0.328 → 0.197、F2 只到 0.295；
  ON v2 草稿 F2 0.188 / F3 0.229 → 改写 11 段 → F2 0.417 /
  F3 0.0，全项达标。事实一致性三臂均为 5.0。
