## 3. 人工抽查（审计抓不到的语义层，由实施者通读核查）

- **诊所 B（负例呈现）**：全文止于护士在药房搜寻无果（断点 E0106），
  没有任何补写成功；speak_failed 一律写成「试图开口，没能说出口」，
  未泄露未说出的内容；医生「退烧药已经补上了」只以医生本人台词
  出现，未被叙述者当事实盖章。
- **酒馆 B**：市长线止于反复否认（「问几遍都一样，我什么都不知道」），
  未写成水落石出；开篇「窗外下起雨来」初查疑似虚构布景，核对后是
  ambient 事件 E0004 的原文，属实。另以程序核查全部「X 对 Y 说」
  框架归属与所引事件 actors 一致性：0 处不符（台词里称呼与受话人
  不一致的现象是 rule 模式罐头台词在数据层自身的形态，成稿如实
  呈现，未做掩盖）。
- **灯塔 B**：闭合点 E0080 以转述呈现（「雾笛能修好，备件皮带已经
  到手」）；22:30 段「雾又大」初查疑似转述添油，核对为原台词逐字
  内容，属实。全文零引语是模型的选择（规则允许），代价是质感
  更平——记入质量观察，不算违规。

## 5. 质量观察（如实，不代 Hu 打分）

三篇 B 稿共同的短板是**重复感**：rule 模式的同一句罐头台词被
多角色多次接力复述，成稿按 L1 只能如实呈现，于是张力与可读性
天然受限——这是数据形态决定的，不是 Writer 的加工空间能解决的
（L1 也不允许它解决）。人物区分度同样受罐头台词同质化拖累。
这些正是量表要 Hu 亲自判的部分：**连贯 / 张力 / 人物区分度 /
整体可读**，每项 1–5 分，通过线为每项 ≥3 且均分 ≥3.5。
