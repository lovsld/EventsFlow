## 1. 做了什么（按任务书 §4 对照）

| 条款 | 实现 | 方式 |
|---|---|---|
| 4.1 统一状态视图 | narrative/character_state.py（新） | 只读聚合既有产物：目标（配置+目标引擎）、知识（弧线学习记录+state.json 信念）、情绪轨迹（psychology 推断）、动机假设（MOTIVATED_BY）、冲突关系（story_views）、弧线。每节标注来源层级 fact / inference / hypothesis，推断永不冒充事实 |
| 4.2 增量状态更新 | psychology.build_state_updates（增强既有模块） | 每条更新含触发事件 id、人物、前后值、原因、证据、置信度、替代解释。事实级（学习）置信度 1.0；无证据锚点的情绪变化不生成更新（诚实剔除后三场计数 36/48/28） |
| 4.3 Planner 读状态 | planner/scene_planner.enrich_scenes_with_states + planner/__init__ 接入 | 每场新增 character_state：逐人物入场目标/已知/不得使用/入场情绪/与同场人物冲突；场景级信息差对、预期状态变化、无预期变化标记。三场 23 场全覆盖，连续性验证仍 0 错误 |
| 4.4 Writer 用心理 | writer2 assemble_context + _prompt（增强） | 提示词新增「人物状态与本场约束」段：目标、入场情绪（标推断与置信度）、不得当作已知的事实、信息差、预期变化；明文禁止说明书式心理旁白，要求以动作/对话/停顿/回避呈现 |
| 4.5 知识约束 | 同上 + 既有 knowledge_at_start / already_revealed | 约束细化到逐人物逐场：入场未掌握的事实只能以猜测形式出现且须表现为猜测 |
| 4.6 关系影响行为 | 状态视图 relationships（冲突类型/核心议题/对方）+ Planner conflicts_with + Writer 相关冲突段 | 关系变化仍只来自事件证据（story_views 冲突源于已提交事件） |
| 4.7 场景后验证 | narrative/scene_verification.py（新） | 确定性三查：未来事件引用、预期事实级学习未被叙述、说明书式心理旁白（启发式、标注待人工判定）。差异只记录、从不自动改文本、从不用计划覆盖文本 |

新模块仅 2 个，理由见审计报告 §5（character_state 为纯聚合
视图、无新存储；scene_verification 与 quality.py 的全书后验
粒度/时机不同）。未新建任何平行的 Character/Psychology/
Goal/Knowledge 系统。

## 4. 反事实测试（§5.4）

同场景（酒馆 SC01）、同事件、同大纲，仅变异士兵状态：
入场已知 anonymous_letter_exists + mayor_embezzled、
入场情绪改为愤怒。产物 phase2/counterfactual/result.json
（Gemini，两次调用约 1.7k 入 / 0.5k 出）。

结果：部分通过。提示词层证明是精确的（差异仅在状态段）。
文本层差异真实但温和：真实状态下士兵是「发现者」姿态
（藏信、屏息、"这可能就是线索"）；变异状态下是「解读
者」姿态（摩挲审视信件、推断商人交易与调查的关联）。
差异在认知姿态与解读框架，不在情节——情节由事件流
固定，这正是本系统的设计边界。愤怒变异在文本中几乎
不可见。另记录一处瑕疵：文本 A 出现原始地点 id
"back_room" 未汉化（素材呈现层问题，与本阶段无关，
列为已知项）。
