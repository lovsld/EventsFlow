# Novel Adaptation Upgrade — Phase 6 报告（Writer 升级 + 质量评价）

日期：2026-11-22。引擎：Gemini `gemini-2.5-flash`（三场同引擎；Writer 与
独立评审为同一模型的两个角色，评审角色与确定性检查共同署名 evaluator）。
预算：Hu 批准硬顶 200k 入 / 60k 出；实际总用量 **37,207 入 / 21,540 出**
（写作 23 场 + 评审 13 章，共 36 次调用），远在顶内。

## 交付物

- `narrative/gemini_client.py`：Gemini 客户端（保险库 surrogate 凭据，
  与 DeepSeek 客户端同等纪律）。号池经 `gemini_pool.txt` 或环境变量
  `ACP_GEMINI_CREDENTIALS` 配置，429/500/503 时轮换凭据并退避重试。
  两个实测要点：（1）gemini-2.5-flash 是思考型模型，思考 token 会吃掉
  输出上限——4k 上限下曾出现 1.4k 思考 token 把 JSON 截断，故本项目
  固定 `thinkingBudget=0`，保真靠装配好的上下文而非思维链；
  （2）新注册的 Google 账号被 Google 关闭了 2.5-flash 的生成权限
  （404 "no longer available to new users"），客户端对这类凭据自动
  回退到其指定的 `gemini-3.8-flash` 并在用量中记录实际模型。本轮三场
  实际全部由 4 把老账号凭据以 2.5-flash 完成，回退路径未被触发到成品。
- `narrative/writer2.py`：大纲驱动的逐场 Writer。每场写作前装配任务书
  要求的九项输入（故事/章节/场景大纲、人物档案=语声样本+弧线摘要、
  场景开始时各角色知情状态、相关冲突、前场结尾状态、未收伏笔、
  本场事件清单），并产出输入清单（manifest）记录每项在场/缺失。
  合并组（semantic merge groups）的重复事件以 `role=repeat of NE-…`
  显式标注给模型、要求不重写——重复问题在结构上解决，不靠模型自觉。
  输出按段标注 F1（事实，须带 event_ids、引文逐字）/ F2（连接性铺陈，
  不得引入新客观事实）/ F3（创造性添加），F3 段落全量登记进
  creative register。视角人物只能使用知情清单内的事实；未决问题保持
  未决。预算保险丝：累计用量触顶即停并记录 `stopped` 原因（本轮未触发）。
- `narrative/quality.py`：12 维评价。6 维确定性本地计算（事实一致性、
  重复度、知识一致性、伏笔收束、场景完整性、章节节奏、冲突推进——
  其中冲突推进为结构代理指标），6 维由独立评审角色逐章打分
  （因果连贯、角色一致、弧线可信、情感变化、对话自然、可读性），
  锚点量表 1/3/5，扣分须引用原文；QualityReport 强制带 evaluator 字段，
  结构上杜绝无标注的自评。伏笔维度在该场没有 payoff 记录时不适用、
  以 info issue 明示并从维度中剔除（故灯塔/诊所为 11 维，酒馆 12 维）。

## 诚实的问题清单

1. **诊所事实一致性 2.0（3 处高严重度违规）**：一处引文与源文本不完全
   一致（"后半夜有个发高烧的要送来"，E0002）；另两处更值得注意——模型把
   动作类事件的系统日志串（`search @ oncall`、`speak_failed @ triage`）
   当作引文写进了正文。这类事件的 observation 文本本身是机器日志而非
   台词，Writer 引用时未做区分。修复方向在输入侧：装配上下文时把动作
   事件的文本标注为「日志、非台词、不可引用」，或在确定性审计中把这类
   串列入禁引清单。本轮未修复，仅记录（成品已按原样交付）。
2. **灯塔事实一致性 4.0**：一处引文不逐字（"好了没有"，E0087）。
3. **对话自然度全面偏低（1.5–2.8）**：评审引用的证据高度一致——源头
   罐头台词被多个角色原样复述。虽然句子级重复率已降到 0–0.013，
   「同一句台词在不同场景被不同人重复说出」属于跨场景的语义重复，
   合并组只压同一场内的重复，跨场景的 relay 链仍进入正文。这是涌现层
   数据的属性（规则模式台词池小），叙事层能缓解、不能根除。
4. **F3 占比偏高（约 40%）**：三场 F3 段落分别为 24/27/26 段。全部已
   登记可审计，但占比说明模型在场景铺陈上出手较重；若后续要收紧，
   可在 prompt 中给 F3 设比例上限。本轮按任务书「F3 必须标记」的口径
   交付，未设上限。
5. 章节节奏（2.14–3.26）为段落数变异系数指标，三场章节长短不均，
   与章节规划按高潮/线索切换收章的策略有关，属结构特征而非错误。
