## 1. 场景构想：「雾汛灯塔」

全新领域：雾汛起头、海上礁石岬角的一座灯塔，夜班将临，
一艘渔船后半夜要贴着暗礁回港。题材与目标结构与酒馆
（查信/保密）、仓库（寻失物）、诊所（补药/交代）均不同：
本题是**设施抢修与信号保障**——雾笛坏了、备件在别处、
船要来了、消息与备件都必须在人与人之间流动起来。

地点拓扑为**路径图 P4**（线性链）：
`boathouse — jetty — base — lamp_room`（度数 1-2-2-1，
无环、无三度枢纽）。与酒馆/仓库的树形图（三度枢纽 +
二长支链）不同构，与诊所的四环加叶不同构。

### 角色（3，性格/私有知识互异）

| 角色 | 起始 | 私有知识（开局仅本人持有） |
|---|---|---|
| keeper_zhou 守塔人 | base | `ship_passing_tonight`（电台记录：渔船今夜贴礁回港，须灯光+雾笛）conf 1.0 experienced |
| lin_tao 维修工 | boathouse | `belt_broken`（傍晚亲查：雾笛空压机皮带已断；备用皮带在 base 储藏柜）conf 0.95 experienced |
| a_gui 接船船员 | jetty | `jetty_lamp_out`（傍晚亲见栈桥信号灯已灭）conf 0.9 experienced |

### 信息不对称链（本题的承重结构）

1. **lin_tao 的抢修目标只能由 keeper_zhou 的消息点火**：
   `repair_fog_horn` 的激活条件是 lin_tao 本人信念
   `ship_passing_tonight ≥ 0.4`，而该命题开局只有 keeper
   持有。没有传讯，抢修永不启动（他只当皮带是明日再修
   的例行故障）。
2. **keeper_zhou 的保障目标只能由 lin_tao 的回报闭合**：
   `ensure_fog_signal`（depends_on 本人的 spread_word）
   的成功条件是 keeper 本人形成 `fog_horn_ready` 信念
   （≥0.5）或亲耳感知 lin_tao 的 horn_report 断言事件；
   该命题的唯一来源是 lin_tao（皮带是雾笛的唯一故障，
   备件到手即他亲手确认可修复——建模约定见场景
   comment，沿诊所「取到备用药盒 = 已补齐」的同一建模
   纬度：spare_belt 的 reveals 给出 fog_horn_ready 0.95）。
3. **第三方支链**：a_gui 的 `learn_ship_news`（信念
   ≥0.6）与 `ready_mooring`（激活 ≥0.4；成功 = 持有
   signal_lantern + 在 jetty + 做过 work）使信息网超出
   职责对子：lantern 在 boathouse 的工具架上，他必须
   离岗去取，途中与 lin_tao 的相遇面构成第二条传讯面。

### 职责（数据声明，profile.disclosure_duties）

- D1 keeper_zhou：信念 ship_passing_tonight ≥0.9 时
  （开局即武装），须向 lin_tao 披露该命题，urgency normal。
- D2 lin_tao：信念 fog_horn_ready ≥0.9 时（取得备件后
  武装），须向 keeper_zhou 回报该命题，urgency normal。

### 目标构成核对（设计 §6.3 逐项）

- ≥3 角色 ✓；≥3 目标相互依赖 ✓（激活链 ×2、depends_on
  ×1、成功条件跨角色 ×1）。
- 跨角色信息传递 ✓（承重链 1/2 + 支链 3）。
- 提问与回答：claims 含 ship_inquire / horn_inquire
  （inquire）与 ship_notice / horn_report（assert），
  数据面具备问答对；实测采样见 K7。
- 自主探索：spare_belt（base 储藏柜）与 signal_lantern
  （boathouse 工具架）均为 searchable 物体，另设三处可
  搜 scenery（jetty 绳箱、lamp_room 日志桌）供探索面。
- ≥1 可失败目标 ✓（设计面）：lin_tao 的维护目标
  `guard_boathouse` 以「他人在 boathouse 搜查」为失败
  条件，而 a_gui 取 lantern 的正当路径正要在 boathouse
  搜查——失败风险由数据内生制造（K8）。
- ≥1 计划需 blocked→recovery：数据面无法强造（计划由
  引擎按目标合成）；以 K9 作观察性判据，如实采样。
