## 1. 摘要

**一句话结论**：V0.2-B 把场景语义从决策代码搬进数据、把「完成」
从执行层搬进条件求值层——B1–B3 三道硬门槛全部通过、全套测试
173/173、酒馆与仓库两场景的目标驱动行为均有轨迹级证据；但它卡
在独立场景 C 上：诊所场景预注册仅命中 2/10、判定「通用性不成
立」，失败不在框架层（新场景纯数据一次装入、冻结零改动、零错误
跑满），而在决策内容层——通用候选机制产不出（或选不出）「主动
断言」，跨角色信息链的第一环在 144 次决策中从未发生。审查 §十
31 条复验：**满足 27、部分 3、未满足 1**（明细见 §9）。

### 7.4 判定：通用性不成立（分层依据）

按预注册标准判定**不成立**：设计因果链（医生断言 → 护士激活 →
搜药获得 → 护士报告 → 医生确认）第一环即断裂，后四环无从谈起；
预注册口径下「链条部分闭合（如激活发生）」才记部分成立，而本场
景激活从未发生，故不记部分成立。

失败的位置须同时界定（不改变判定）：**框架层成立**——带环的新地
点图、新角色、新物品、新命题纯靠数据一次装入，两场零错误跑满，
目标暂停/进度、矛盾推断、会话、候选评分落盘等机制在新场景里照
常运转；**决策内容层不成立**——通用候选生成能稳定产出询问与观
察，却产不出（或选不出）主动断言与定点搜查。与 V0.2-A 实验 3b
的「行为同质化」相比，这次的形态是「行为分化了，但分化成三种各
自锁死的低产出循环」（游走的护士、复读提问的护工、观察的医生）。
场景 B 的对照恰好点明分界：B 的链条第一环是「私人知识直接激活
+ 搜查」，不依赖任何人开口；C 故意把第一环放在「跨角色断言」
上，而断言正是当前机制下最弱的一环。

### 7.5 契约缺口（10 条，摘要；全文见场景 C 报告 §5）

1. 无任何契约手段能让「主动断言」可靠发生：claims 只定义断言资
   格，不定义知情者被询问时为何选 assert；唯一的「职责」杠杆
   （event_occurred{claim} 型目标）会被暂停规则静默压过。
2. 目标暂停规则对数据作者不可见且无数据侧制衡：无「不可暂停 /
   优先级下限 / 公平轮换」字段，暂停与恢复条件无从预知。
3. testimony 可靠度调制公式未进入面向作者的契约面：公式存在于
   设计 §3.5，但架构/契约文档无公式无示例，激活线与完成线只能
   盲猜（预注册风险 R1 坐实）。
4. search 候选的产生条件对作者不透明：无法从契约得知搜查由什么
   触发，「让某人去搜某处」不可设计、只能照抄样例形状。
5. session / interrupted / speak_failed 等会话机制不在契约内：
   「两人同场」与「话说出口」之间隔着未文档化的会话层。
6. agent_at_location 叶是瞬时量、非闩锁：progress 随进出地点
   0↔0.5 闪烁倒退，「到某地做某事」型目标天然脆弱且契约未提醒。
7. conceals:<agent> 信念的键格式与强度（恒 0.8）不在契约内：
   「识破隐瞒」类目标在数据层不可设计。
8. 无持有者物品（公共物品）的表达方式不明确：holder 可否为 null、
   seen_by 为空时可否被搜到，契约未言。
9. priority_rules 的 when/delta/once 只有一行描述：格式靠猜、效果
   无从验证（本场景试用一次，因条件未满足而从未触发）。
10. 「物品 reveals → 持有者自知 → 可对外断言」的完整言语报告链
    无走通的样例可抄，只能由酒馆信件样例类推。

## 10. 已知限制汇总（合并实施报告 §8 与场景 C 缺口，去重后分类）

**机制缺口**

1. 主动断言不被可靠产生/选中：claims 只给断言资格，通用候选机制
   稳定产出询问与观察，却不保证知情者在被询问或负有信息职责时
   assert——C 的链条因此在第一环断裂（C 缺口 1，本轮最重要发现）。
2. 目标暂停压过职责型目标：event_occurred{claim} 型目标会在 tick 0
   被计划追逐暂停且可长达全程不恢复，数据侧无制衡（C 缺口 2）。
3. 定点搜查不可设计：search 候选的触发条件不透明，无目标牵引时
   角色站在可搜地点也不会搜查（C 缺口 4）。
4. 「步」粒度偏粗：酒馆合成步的成功条件即目标叶本身，步完成率
   ≈0.028，blocked→replan 成为主导动力学形态（实施报告 §8.2）；
   另 location 叶非闩锁使 progress 闪烁倒退（C 缺口 6）。
5. 酒馆目标完成率在 B 口径下仍为 0（5/5 种子）：若干目标依赖场景
   供给的命题通道（mayor_cleared 无人断言），按设计可能永不完成，
   未加特殊规则（实施报告 §8.1）；完成证据目前只来自场景 B。
6. goal deadline 仍无到期语义（沿 V0.2-A 未采纳项）；
   objective 域谓词仅供实验层、运行时无消费者（按设计）。

**契约与文档缺口**

7. 目标暂停/恢复条件对数据作者不可见，契约无 unpausable / 优先级
   下限之类字段（C 缺口 2）。
8. testimony 可靠度调制公式未进入面向作者的契约面：公式在设计
   §3.5，架构文档与样例中无公式、无数值示例，阈值设计只能盲猜
   （C 缺口 3）。
9. 会话机制（session / interrupted / speak_failed）与
   conceals:<agent> 的键格式/强度不在契约内（C 缺口 5、7）。
10. 无持有者物品的表达、priority_rules 的完整语义、reveals→持有
    →断言 的完整报告链样例，均缺契约级说明（C 缺口 8、9、10）。

**证据缺口**

11. LLM 路径无真实模型轨迹：legacy 步在 LLM 自由文本计划下的占比
    待真实运行时如实统计；阻塞处理在 LLM 侧仅有契约与 mock 证据。
12. 动态激活与 failure/abandon 的轨迹样本薄（§9 Goal 组第 1、6 条
    记「部分」的原因）；运行内 priority_rules 触发样本为 0。
13. 反事实证据限于信念层：目标话语改钉后测得客观不分岔、信念层
    Δ=0.104（§6）——客观行为层面的反事实效应在本动力学下不存在，
    这是测量结论而非实验失败，但证据强度以此为限。

## 11. 下一步建议（结论，本报告不执行）

在启动 Narrative Observer 之前，先做一轮针对性修复，只处理三件
已被证据点名的事：

1. **主动断言的选择机制**：让知情且负有信息职责的角色能可靠
   assert——候选可由目标条件派生断言候选并赋足权重（例如目标的
   success/activation 条件引用某 claim 时，为持有该信息的角色生
   成对应的 assert 候选），或在数据契约中引入可声明的 disclosure
   duty 字段；同时把「被询问且持有答案时的 assert 响应」做成与
   inquire 对等的通用候选来源并写进契约。
2. **目标暂停规则契约化**：把暂停条件与恢复条件写进契约文档并对
   数据作者可见，给数据侧制衡字段（如 unpausable、priority
   floor），使职责型目标不会被计划追逐静默压死。
3. **testimony 可靠度公式进契约文档**：给出调制公式与至少一个数
   值示例（沿用设计 §3.5 的口径），使激活/完成阈值在纸面可算、
   可验证。

修复后按同一冻结协议复测，但须用**全新场景**（诊所场景的设计已
对实现方可见，重跑它等于对着已知答案调参，不再构成独立证据）；
复测的预注册应继续把「跨角色断言点火」设为链条第一环的验收点。
在此之前，审查 §十的门槛未全清（通用性第 5 条未满足），**不建议
启动 Narrative Observer 开发**。
